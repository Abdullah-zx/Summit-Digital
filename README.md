# Summit Digital

A modern, responsive website for Summit Digital, focused on providing digital solutions to construction businesses in Australia.

## Overview

Summit Digital helps construction companies improve their online presence through website development, website optimisation, SEO, and lead generation.

This website provides information about the company's services and allows potential clients to submit enquiries through a contact form.

## Features

- Modern and responsive website design
- Mobile-friendly navigation
- Services showcase
- Contact and enquiry form
- Client enquiry email notifications
- Form validation
- Interactive UI elements and animations
- Google Apps Script email integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Gmail Mail Service

## Contact Form

The contact form uses Google Apps Script as its backend to process enquiries and send email notifications to:

**summitdigital.contact@gmail.com**

It does not require a traditional hosting server or database.
